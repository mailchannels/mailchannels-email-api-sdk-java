

# MailSendBodyUnsubscribeSettings

Settings to customize the unsubscribe experience for the message. 

## Properties

| Name | Type | Description | Notes |
|------------ | ------------- | ------------- | -------------|
|**customDomainName** | **String** | The name of a configured active unsubscribe tracking domain. When specified, unsubscribe links will use this domain instead of the default MailChannels domain. The domain must be registered in your account and have an active status.  |  [optional] |
